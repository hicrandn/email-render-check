# Mail Check

A preview tool that shows how your email HTML renders across major email
clients (Gmail, Outlook Windows/Word, Outlook.com, Apple Mail, Yahoo) and
flags incompatibilities — which client, which feature, and why.

## Commands

```bash
npm run dev              # start the dev UI at http://localhost:3000
npm run build            # production build
npm test                 # run the test suite
npm run update-caniemail # refresh the email client support data
npm run lint             # eslint
```
