# Mail Check

A preview tool that shows how your email HTML renders across major email
clients (Gmail, Outlook Windows/Word, Outlook.com, Apple Mail, Yahoo) and
flags incompatibilities — which client, which feature, and why.

## Commands

```bash
pnpm dev                # start the dev UI at http://localhost:3000
pnpm build              # production build
pnpm test               # run the test suite
pnpm update-caniemail   # refresh the email client support data
pnpm lint               # eslint
```
